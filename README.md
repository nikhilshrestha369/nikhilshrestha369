## About

I build cross-platform mobile applications, mostly with Flutter and Dart. My work so far has come out of workshops, internships, and personal projects — a workshop booking system, a few small games, and a portfolio app. I spend most of my time on UI work and app structure, and I'm currently filling in the gaps around state management and backend integration.

Outside of that I'm a C++ learner, which is a slower and more painful process than it should be.
